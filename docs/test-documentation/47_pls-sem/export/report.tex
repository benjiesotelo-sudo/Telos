Like CB-SEM but variance-based and prediction-oriented (good for smaller samples / formative constructs). PLS-SEM does not use CB-SEM global fit indices (CFI/TLI/RMSEA) --- judge it instead by reliability \& validity (CR, AVE, HTMT), then R\textsuperscript{2}, Q\textsuperscript{2} (predictive relevance) and f\textsuperscript{2}, with SRMR the only commonly reported approximate fit index. Read the bootstrapped path coefficients ($\beta$, p); f\textsuperscript{2} is each path's effect size (\textasciitilde{}0.02 small, 0.15 medium, 0.35 large).

In the PLS-SEM, the path from esg to intent gave $\beta$=.35, p $<$ .001 (bootstrap); R\textsuperscript{2}Y=.34.

Statistical basis: PLS-SEM estimation (seminr) (Ray S, Danks N, Calero Vald\'{e}z A (2021). seminr: Domain-Specific Language for Building PLS Structural Equation Models. R package.); Discriminant validity via HTMT $<$ .85/.90 (Henseler, J., Ringle, C. M., Sarstedt, M. (2015). "A new criterion for assessing discriminant validity in variance-based structural equation modeling." Journal of the Academy of Marketing Science, 43(1), 115-135.); f\textsuperscript{2} effect-size benchmarks (.02/.15/.35) (Cohen, J. (1988). Statistical Power Analysis for the Behavioral Sciences (2nd ed.). Routledge.); PLS-SEM reporting standard (no global fit indices; judge by reliability/validity then R\textsuperscript{2}/Q\textsuperscript{2}/f\textsuperscript{2}) (Hair, J. F., Risher, J. J., Sarstedt, M., Ringle, C. M. (2019). "When to use and how to report the results of PLS-SEM." European Business Review, 31(1), 2-24.); Two-stage latent moderation via an interaction construct (Henseler, J., Chin, W. W. (2010). "A comparison of approaches for the analysis of interaction effects between latent variables using partial least squares path modeling." Structural Equation Modeling, 17(1), 82-109.); Simple slopes at -1SD/mean/+1SD (Aiken, L. S., West, S. G. (1991). Multiple Regression: Testing and Interpreting Interactions. Sage.).
